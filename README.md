# JaydeepB Portfolio

A static portfolio website for Jaydeep Biswas featuring Nocturne Kitchen, recOCare, web development, UI/UX design and short-form video editing.

## Files

- `index.html` — website content, links and sections
- `styles.css` — colors, typography, layout and animations
- `script.js` — interactions, tabs, cursor effects and scroll animation
- `nocturne-portfolio.png` — Nocturne project image
- `assets/recocare-portal.png` — recOCare project image

## Edit the portfolio

Open the folder in VS Code:

1. Edit text and links in `index.html`.
2. Edit colors, spacing and design in `styles.css`.
3. Edit interactions in `script.js`.
4. Replace an image while keeping the same filename, or update its path in `index.html`.

## Preview locally

Because this is a static website, you can double-click `index.html` to preview it. For a better development preview, install the Live Server extension in VS Code, right-click `index.html`, and select **Open with Live Server**.

## Host on Vercel

1. Create a new GitHub repository.
2. Upload all files and folders from this project. Keep `index.html` at the repository root.
3. In Vercel, select **Add New → Project**.
4. Import the GitHub repository.
5. Leave **Framework Preset** as **Other**.
6. Leave Build Command and Output Directory empty.
7. Select **Deploy**.

After future edits, commit and push them to GitHub. Vercel will automatically redeploy the website.
